# Royal Warriors Martial Arts Website

## Files
- `index.html` — Main website
- `style.css` — Website design and responsiveness
- `script.js` — Mobile menu and WhatsApp enquiry form
- `logo.jpg` — Royal Warriors Martial Arts logo

## Deploy with Netlify

### Option 1: GitHub + Netlify
1. Create a new GitHub repository.
2. Upload all four website files.
3. Go to Netlify and choose **Add new site**.
4. Select **Import an existing project**.
5. Connect GitHub and select your repository.
6. For this plain HTML website, no build command is needed.
7. Publish the site.

### Option 2: Direct Netlify deployment
You can also drag the website folder into Netlify's manual deploy area.
